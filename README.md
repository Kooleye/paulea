# Витрина магазина одежды для Telegram

Мини-приложение без онлайн-оплаты: клиент смотрит каталог, выбирает размер,
складывает вещи в корзину и отправляет заявку. Заявка прилетает менеджеру в Telegram.

**Зависимостей нет.** Нужен только Node.js. Никакой `npm install` делать не надо.

---

## Шаг 1. Установите Node.js

Скачайте версию **LTS** с официального сайта nodejs.org и установите с настройками по умолчанию.
Проверьте, что всё встало — откройте терминал и выполните:

```
node -v
```

Должна появиться версия вида `v20.x` или выше. Минимум — 18.

Где искать терминал:
- **Windows** — меню Пуск → наберите `PowerShell`
- **macOS** — Launchpad → Программы → Утилиты → Терминал

---

## Шаг 2. Распакуйте архив

Распакуйте `tg-shop.zip` в любую папку — например, на Рабочий стол.
Важно: именно распакуйте, а не просто откройте архив двойным кликом.

---

## Шаг 3. Запустите

### Самый простой способ

- **Windows** — дважды кликните по файлу `START-Windows.bat`
- **macOS / Linux** — в терминале перейдите в папку проекта и выполните `sh START-Mac-Linux.command`

### Способ через терминал

Перейдите в папку проекта и запустите сервер:

```
cd путь/к/tg-shop
node server.js
```

Совет: вместо того чтобы печатать путь вручную, наберите `cd ` и перетащите папку в окно терминала.

В терминале появится адрес. Откройте его в браузере:

- Витрина: `localhost:3000`
- Админка: `localhost:3000/admin.html` (пароль по умолчанию `admin`)

Чтобы остановить сервер — `Ctrl + C` в терминале.

> Витрина свёрстана под телефон. В браузере удобнее всего смотреть её в режиме
> мобильного устройства: `F12` → значок телефона в панели разработчика.

## Шаг 4. Подключите уведомления менеджеру

Пока Telegram не настроен, заявки просто печатаются в терминале и видны в админке.
Чтобы они приходили в чат:

1. В Telegram найдите **@BotFather** → `/newbot` → придумайте имя и адрес бота.
   Он пришлёт токен вида `1234567890:AAH...`.
2. Создайте в Telegram группу для заявок и добавьте в неё своего бота как участника.
3. Узнайте `chat_id` группы: добавьте туда бота **@getmyid_bot** или **@RawDataBot**,
   он покажет номер вида `-1001234567890`. Потом его можно удалить.
4. Переименуйте файл `.env.example` в `.env` и впишите туда токен и номер группы.
5. Перезапустите сервер.

---

## Шаг 5. Замените товары на свои

1. Положите фотографии в папку `public/photos/`.
   Соотношение сторон — 3:4 (например, 1200×1600 px), формат JPG или WebP.
2. Откройте файл `data/db.json` в любом текстовом редакторе и отредактируйте
   названия, описания, цены, размеры и имена фото.
3. Остатки по размерам удобнее менять прямо в админке. Остаток `0` — размер
   показывается зачёркнутым и его нельзя заказать.

Фотографии в комплекте — демонстрационные, сгенерированные. Замените их своими съёмками.

---

## Шаг 6. Публикация в Telegram (когда будете готовы)

Telegram открывает мини-приложения только по HTTPS, поэтому `localhost` ему не подходит.
Сначала всё отладьте локально, потом:

1. Выложите папку на сервер с HTTPS (VPS с Node.js и nginx либо любой хостинг Node-приложений).
   Для быстрой проверки на телефоне годится туннель: `npx localtunnel --port 3000` или cloudflared.
2. В @BotFather: `/mybots` → ваш бот → **Bot Settings** → **Menu Button** → вставьте адрес витрины.
3. Откройте бота в Telegram — внизу появится кнопка, открывающая магазин.
4. В `.env` поставьте `ALLOW_BROWSER=false` — тогда заявки будут приниматься только
   из Telegram, с проверкой подписи пользователя.

## Что где лежит

```
tg-shop/
├─ server.js            сервер: каталог, заявки, админка, отправка в Telegram
├─ data/db.json         все данные: категории, товары, остатки, заявки
├─ public/index.html    витрина
├─ public/app.js        логика витрины и корзины
├─ public/styles.css    оформление (подхватывает тему Telegram)
├─ public/admin.html    админка
├─ public/photos/       фотографии товаров
├─ .env.example         шаблон настроек
└─ CLAUDE.md            контекст для доработки через Claude Code
```

## Если что-то пошло не так

| Проблема | Решение |
| --- | --- |
| `node: command not found` | Node.js не установлен или нужно закрыть и снова открыть терминал |
| `EADDRINUSE` | Порт 3000 занят. Запустите `PORT=3001 node server.js` |
| Страница пустая | Проверьте, что сервер всё ещё запущен в терминале |
| Заявка не пришла в чат | Бот не добавлен в группу или неверный `chat_id` в `.env` |
| Сломался `db.json` | Откройте файл и проверьте запятые и кавычки — это обычный JSON |
