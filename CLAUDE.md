# Контекст проекта для Claude Code

Витрина магазина женской одежды для Telegram Mini App. Владелец — не разработчик.

## Главные правила

1. **Никакой онлайн-оплаты.** Не добавлять эквайринг, ЮKassa, СБП, кассы. Корзина → заявка → менеджер связывается сам.
2. **Ноль зависимостей.** Только встроенные модули Node.js 18+. Не добавлять npm-пакеты, сборщики, фреймворки без явной просьбы. Запуск всегда должен оставаться `node server.js`.
3. **Одна база — `data/db.json`.** Обычный JSON, владелец правит его руками. Не мигрировать на SQL без просьбы.
4. **Цена и наличие всегда берутся из базы на сервере**, никогда не из тела запроса клиента.
5. **Комментарии и тексты интерфейса — на русском.**

## Структура

- `server.js` — HTTP-сервер на `node:http`, раздача `public/`, API, отправка в Telegram.
- `data/db.json` — `shop`, `categories`, `products`, `orders`, `orderCounter`.
- `public/app.js` — витрина, hash-роутинг: `#/`, `#/c/<categoryId>`, `#/p/<productId>`, `#/cart`, `#/done/<number>`.
- `public/admin.js` — админка, авторизация через заголовок `x-admin-password`.
- `public/styles.css` — цвета через CSS-переменные темы Telegram с запасными значениями для браузера.

## API

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/catalog` | категории и товары для витрины |
| POST | `/api/orders` | создать заявку и уведомить менеджера |
| GET | `/api/admin/state` | заявки и товары (нужен пароль) |
| POST | `/api/admin/order-status` | сменить статус заявки |
| POST | `/api/admin/product` | создать или обновить товар |
| POST | `/api/admin/product-delete` | удалить товар |

Статусы заявок: `new`, `contacted`, `confirmed`, `done`, `cancelled`.

## Безопасность

- Подпись `initData` проверяется через HMAC-SHA256, секрет = HMAC("WebAppData", токен бота). Данные старше суток отклоняются.
- `ALLOW_BROWSER=true` разрешает заявки без подписи — только для локальных тестов. На боевом сервере должно быть `false`.
- Секреты только в `.env`, никогда в коде и не в git.
